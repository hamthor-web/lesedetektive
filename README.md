# Lesedetektive

Drei Lesespiele mit Profilen, normalem Spiel und Zeitrunden.

[App öffnen](https://hamthor-web.github.io/lesedetektive/)

Direkt auf index.html starten. Alle Dateien zusammen veröffentlichen; für Installation und Offline-Nutzung ist HTTPS erforderlich. Auf Android erscheint bei unterstützten Browsern der Installationsdialog, auf iPhone/iPad führt der Button durch die Schritte zum Home-Bildschirm.

Weitere Angaben zu Varianten, Ergebnissen und gespeicherten Daten: [PROJEKTSTAND.md](PROJEKTSTAND.md).

Über das kleine „i“ bei der Profilwahl und in der Spielauswahl bzw. „Info und Kontakt“ im Spielmenü sind Webseite, Impressum, Datenschutz und die E-Mail-Adresse der Entwicklerin erreichbar. Das Info-Fenster ist offline verfügbar; die verlinkten Webseiten benötigen Internet.
